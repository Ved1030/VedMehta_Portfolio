# AI Developer Portfolio – Requirements Document

## 1. Application Overview

### 1.1 Application Name

**Ved Mehta – AI Developer Portfolio**

### 1.2 Application Purpose

The application is a **modern one-page portfolio website** designed to showcase the work, skills, projects, and achievements of **Ved Mehta**, a Software & AI Developer.

The portfolio will highlight:

* AI/ML projects
* Full-stack development work
* Hackathon achievements
* Technical skills
* Professional experience

The website should present the developer as a **modern AI engineer and full-stack developer**, using a **futuristic cyberpunk aesthetic** with **smooth animations, glowing UI elements, and interactive sections**.

### 1.3 Target Audience

* Recruiters
* Startup founders
* Tech companies
* Hackathon judges
* Collaborators and open-source communities

### 1.4 Key Objectives

The portfolio should:

* Present the developer as a **high-skill AI & full-stack engineer**
* Highlight **major projects like AURA, ChronoCancer, and TrustWealth AI**
* Showcase **hackathon achievements and internship experience**
* Demonstrate **modern web design and development skills**
